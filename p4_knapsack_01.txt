
def knapsack_01(values, weights, W):
    n = len(values)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(W + 1):
            dp[i][w] = dp[i - 1][w]
            if weights[i - 1] <= w:
                dp[i][w] = max(dp[i][w], values[i - 1] + dp[i - 1][w - weights[i - 1]])

    chosen, w = [], W
    for i in range(n, 0, -1):
        if dp[i][w] != dp[i - 1][w]:
            chosen.append(i)
            w -= weights[i - 1]
    return dp[n][W], sorted(chosen)

if __name__ == "__main__":
    values  = [60, 100, 120]
    weights = [10, 20, 30]
    W = 50
    best, items = knapsack_01(values, weights, W)
    print("Values :", values)
    print("Weights:", weights, "| Capacity:", W)
    print("Maximum value:", best)
    print("Items chosen (1-indexed):", items)










"""
0/1 knapsack
Aim: maximum value when each item is taken whole or left out.
Problem: the same data as Practical 3, capacity 50, but no splitting.
Method: dynamic programming with a table dp[i][w].
Recurrence: dp[i][w] = max(dp[i-1][w], value[i] + dp[i-1][w - weight[i]]), which means skip it or take it.
Working: C alone plus B’s best at the remaining capacity gives 120 + 100 = 220. Backtracking over the table finds the chosen items.
Complexity: O(n·W) time and space.
Output: maximum value 220, items 2 and 3. It is less than 240 because C can’t be split. Greedy fails here.
"""




explanation - 
P4: 0/1 knapsack

What it is about: the same bag and items, but no cutting. Each item is taken fully or left out. Greedy fails, so we use a DP table.

Section 1: Make the table

Line: def knapsack_01(values, weights, W):
Makes a function taking values, weights and capacity.

Line: n = len(values)
n is the number of items (3).

Line: dp = [[0] * (W + 1) for _ in range(n + 1)]
Makes a table of zeros with 4 rows (0 to 3 items) and 51 columns (bag size 0 to 50). dp[i][w] means the best value using the first i items with bag size w. Row 0 stays 0.

Section 2: Fill the table

Line: for i in range(1, n + 1):
Go through the items one by one.

Line: for w in range(W + 1):
For each item, go through every bag size 0 to 50.

Line: dp[i][w] = dp[i - 1][w]
Option 1, skip the item. Copy the value from the row above.

Line: if weights[i - 1] <= w:
Option 2, take the item, but only if it fits. (i - 1 because lists start at 0.)

Line: dp[i][w] = max(dp[i][w], values[i - 1] + dp[i - 1][w - weights[i - 1]])
Value of taking = item’s value + best value for the leftover space (from the row above). max keeps the better of skip and take.

Last cell example (3 items, bag 50): skip = 160, take = 120 + 100 = 220. The answer is 220.

Section 3: Find the chosen items

Line: chosen, w = [], W
An empty list for chosen items, and w starts at full capacity.

Line: for i in range(n, 0, -1):
Walk backwards from the last item to the first.

Line: if dp[i][w] != dp[i - 1][w]:
If the value changed when item i was added, item i was taken.

Line: chosen.append(i)
Note the item.

Line: w -= weights[i - 1]
Reduce the bag space by its weight.

Line: return dp[n][W], sorted(chosen)
Return the best value (last cell) and the chosen items in order.

Step by step:

Item 3: 220 ≠ 160, so taken. Space left 20.
Item 2: 100 ≠ 60, so taken. Space left 0.
Item 1: no change, so not taken.
Section 4: Main part

Lines: values = [60, 100, 120], weights = [10, 20, 30], W = 50
The input data.

Line: best, items = knapsack_01(values, weights, W)
Calls the function and stores the result.

Lines: the four print lines
Print the values, weights, capacity, maximum value, and chosen items.

Output explanation
Maximum value: 220
Items chosen (1-indexed): [2, 3]
Items 2 and 3 (B and C): 100 + 120 = 220, weight 50.
Less than 240 in P3 because C can’t be cut.
Greedy would take A and B (160), and C wouldn’t fit, so greedy is worse.
Complexity: O(n × W).
