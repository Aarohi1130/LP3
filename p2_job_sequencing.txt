# Practical 2: Job sequencing with deadlines (greedy)

def job_sequencing(jobs):
    # jobs: list of (job_id, deadline, profit)
    jobs = sorted(jobs, key=lambda x: x[2], reverse=True)   # highest profit first
    max_d = max(j[1] for j in jobs)
    slot = [None] * (max_d + 1)                              # slot[1..max_d]
    total = 0
    for jid, d, p in jobs:
        for t in range(min(d, max_d), 0, -1):                # latest free slot <= deadline
            if slot[t] is None:
                slot[t] = jid
                total += p
                break
    return slot[1:], total

if __name__ == "__main__":
    jobs = [('J1', 2, 100), ('J2', 1, 19), ('J3', 2, 27), ('J4', 1, 25), ('J5', 3, 15)]
    print("Jobs (id, deadline, profit):", jobs)
    seq, profit = job_sequencing(jobs)
    print("Job sequence :", seq)
    print("Total profit :", profit)





"""
Job sequencing with deadlines
Aim: get maximum profit by scheduling jobs, each taking 1 unit of time.
Problem: a job earns its profit only if it finishes by its deadline, and one job runs per slot.
Method: greedy. Sort by profit in descending order, then put each job in the latest free slot on or before its deadline. Skip it if none is free.
Data: J1 (2, 100), J2 (1, 19), J3 (2, 27), J4 (1, 25), J5 (3, 15).
Working: J1 goes to slot 2, J3 to slot 1, J5 to slot 3, and J4 and J2 are rejected.
Complexity: O(n²) in the worst case, or O(n log n) with union-find.
Output: sequence J3, J1, J5 with profit 142.
"""



explanation - 
P2: Job sequencing with deadlines

What it is about: 5 jobs, each takes 1 hour, has a deadline and a profit. A job earns its profit only if done by its deadline. One job per hour. Find the maximum profit.

Section 1: Sort the jobs

Line: def job_sequencing(jobs):
Makes a function that takes the list of jobs.

Line: jobs = sorted(jobs, key=lambda x: x[2], reverse=True)
Sorts the jobs by profit (x[2] is the 3rd item), highest first. This is the greedy idea: the most valuable job gets the first chance.
Order: J1 (100), J3 (27), J4 (25), J2 (19), J5 (15).

Section 2: Prepare the timetable

Line: max_d = max(j[1] for j in jobs)
Finds the largest deadline (j[1] is the deadline). Here it is 3, so we need 3 slots.

Line: slot = [None] * (max_d + 1)
Makes empty slots: [None, None, None, None]. One extra box so slot numbers 1, 2, 3 match list positions. Position 0 is unused.

Line: total = 0
Total profit starts at 0.

Section 3: Place each job

Line: for jid, d, p in jobs:
Take jobs one by one in sorted order. jid is the name, d the deadline, p the profit.

Line: for t in range(min(d, max_d), 0, -1):
Check slots backwards from the job’s deadline down to slot 1. Using the latest slot keeps earlier slots free for tight-deadline jobs.

Line: if slot[t] is None:
Is this slot empty?

Line: slot[t] = jid
Yes, so put the job in this slot.

Line: total += p
Add the job’s profit to the total.

Line: break
Stop searching, since the job is placed. If no slot was free, the job is skipped.

Step by step:

Job	What happens	Timetable
J1 (d=2)	slot 2 free, placed	- J1 -
J3 (d=2)	slot 2 full, slot 1 free, placed	J3 J1 -
J4 (d=1)	slot 1 full, rejected	J3 J1 -
J2 (d=1)	slot 1 full, rejected	J3 J1 -
J5 (d=3)	slot 3 free, placed	J3 J1 J5
Section 4: Return

Line: return slot[1:], total
Gives back the timetable without the unused position 0, and the total profit.

Section 5: Main part

Line: jobs = [('J1', 2, 100), ('J2', 1, 19), ('J3', 2, 27), ('J4', 1, 25), ('J5', 3, 15)]
The input. Each job is (name, deadline, profit).

Line: seq, profit = job_sequencing(jobs)
Calls the function and stores the timetable and total profit.

Lines: the three print lines
Print the input, the job sequence, and the total profit.

Output explanation
Job sequence : ['J3', 'J1', 'J5']
Total profit : 142
Hour 1 is J3, hour 2 is J1, hour 3 is J5.
Profit = 27 + 100 + 15 = 142.
J2 and J4 were rejected because slot 1 was already taken by J3, who pays more.
Complexity: O(n²)
